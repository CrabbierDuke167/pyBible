## 📌 Overview

**pyBible** was never meant to be this elaborate, what started as a small python project to learn csv handling ended up in a full stack website.

---

## 🛠️ Tech Stack

- **Backend:** Python 3.10+, Flask, `csv`, `requests`, `os`
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6 Async/Await)
- **Icons & Fonts:** Phosphor Icons, Google Fonts (`Space Grotesk`)
- **Web Server (Production):** Gunicorn / WSGI
